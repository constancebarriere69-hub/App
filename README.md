# Русский каждый день — Apprendre le russe tous les jours

Application web pour apprendre le russe au quotidien : alphabet, grammaire,
prononciation, orthographe, fiches mentales, histoires à lire et à écrire,
et podcasts générés à partir du vocabulaire appris.

## Démarrer

```bash
npm install
npm run dev
```

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- React Router
- Zustand (progression persistée en localStorage)
- Synthèse vocale du navigateur (Web Speech API) pour la prononciation et les podcasts
